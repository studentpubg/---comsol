## 1. Comsol当中2D仿真建模和怎么提取有效折射率
comsol里面仿真比较简单，也是为了方便理解计算和提取有效折射率，可以按照我下面步骤跟着操作<br>


<p align="center">下面是我耦合波导模型</p><br>

<div align="center">
  
  ![我的耦合波导模型仿真图](<耦合波导模型.png>)
</div>

> [!NOTE]
> ncore=1.548[um]--纤芯折射率<br>
nclad=1.540[um]--包层折射率<br>
lda=700[nm]--波长<br>
r=1.9[um]--波导半径，这里面我设置了两个波导,两个波导都是一样的半径<br>
d=5[um]--这个是两个波导之间的距离大小<br>


1. 这样就是 Comsol 里面的 2D 建模参数设置：
   - 外面可以设置一个正方形的包层，包层的边长可以设置为20*r的大小
   - 两个波导可以对称放置，一个波导位置在d/2$，另一个在-d/2


2.  Comsol里面怎么找有效折射率操作：
     - 首先在comsol研究里面有一个`模式分析`，其中的围绕偏移量搜索模式可以是1.544开始，搜索模式可以是8，原因是设置了两个波导，那么一个波导有两个OAM模式，一个为正，一个为负，那么两个模式当中都有垂直和水平的
     - 同时在添加一个参数化扫描，扫描两个波导之间的距离d,从5扫到15，最好不超过正方形包层边界，步长可以设置为0.1,最后点击计算！
     - 计算之后，可以在结果当中添加一个全局计算，计算有效折射率，也就是neff
     - 结果当中添加一个一维绘图组，并添加全局，数据集就选择刚刚参数化扫描的数据，纵坐标就是neff，横坐标设置为d就可以得到下图
