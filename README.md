## 1. Comsol当中2D仿真建模和怎么提取有效折射率
comsol里面仿真比较简单，也是为了方便理解计算和提取有效折射率，可以按照我下面步骤跟着操作<br>


<p align="center">下面是我耦合波导模型</p><br>

<div align="center">
  
  ![我的耦合波导模型仿真图](<耦合波导模型.png>)
</div>

> [!NOTE]
> - ncore=1.548[um]--纤芯折射率<br>
> - nclad=1.540[um]--包层折射率<br>
> - lda=700[nm]--波长<br>
> - r=1.9[um]--波导半径，这里面我设置了两个波导,两个波导都是一样的半径<br>
> - d=5[um]--这个是两个波导之间的距离大小<br>

1. 上面note里面这样就是 Comsol 里面的 2D 建模参数设置：
   - 外面可以设置一个正方形的包层，包层的边长可以设置为20*r的大小
   - 两个波导可以对称放置，一个波导位置在d/2，另一个在-d/2

2.  Comsol里面怎么找有效折射率操作：
     - 首先在comsol研究里面有一个`模式分析`，其中的围绕偏移量搜索模式可以是1.544开始，搜索模式可以是8，原因是设置了两个波导，那么一个波导有`两个OAM模式`，一个为正，一个为负，那么两个模式当中都有垂直和水平的
     - 同时在添加一个`参数化扫描`，扫描两个波导之间的距离d,从5扫到15，最好不超过正方形包层边界，步长可以设置为0.1,最后点击计算！
     - 计算之后，可以在结果当中添加一个`全局计算`，计算`有效折射率`，也就是neff
     
> [!NOTE]
> - 再回到第一步围绕偏移量搜索模式改为刚刚全局计算的neff，我的是1.5408459<br>
> - 然后在结果当中添加一个`一维绘图组`，并添加`全局`，数据集就选择`刚刚参数化扫描的数据`，纵坐标就是neff，横坐标设置为d就可以得到下图

> [!NOTE]
> 注意代码当中里面在不同d情况下可以看见不一样的有效折射率<br>
> 我就想看一个大概趋势，可以自己加入不同情况下的d的有效折射率<br>


<mark style="background-color: #ffebe9; color: #cf222e;">代码当中需要注意有效折射率的大小，我进行了一个降序排列</mark><br>

<mark style="background-color: #ffebe9; color: #cf222e;">就可以利用分块矩阵的性质进行计算得到结果和各个耦合系数的表达式 </mark><br>
